# Changelog

All notable changes to typecheck are documented here.

## [1.0.0] — 2026

### Added
- Typing test engine with 5 modes (time, words, quote, zen, custom)
- Real-time race with public/private rooms and passcodes
- Analytics dashboard with keyboard error heatmap and finger breakdown
- Weak-key coach with targeted drills and smart sentence generation
- Replay theater with keystroke-level scrubbing
- Daily challenge with seeded words and streak tracking
- FUT-style season card with PNG export
- Mechanical keyboard sounds (WebAudio, pre-warmed)
- Ghost pace (replay your best run keystroke-for-keystroke)
- Adaptive difficulty
- Vocabulary deck with 30% injection
- Health nudge (Pomodoro + stretch reminders)
- Hand guide (SVG finger hint)
- Rhythm metronome mode
- Streamer overlay route (/overlay)
- 6 themes (Graphite, Ink, Paper, Midnight, Forest, Rose)
- PWA with offline support
- Accessibility: dyslexia font, high contrast, focus mode, breathing bar
- Custom text mode with GitHub file fetch
- CSV export for history and race results
